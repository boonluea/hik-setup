การตั้งค่า NVR hik ด้วย web config.
1. เลือกภูมิภาค
2. ตั้ง password 


การติดตั้งระบบ hik-face
1. ติดตั้ง ubuntu desktop 24.04.3 LTS. https://ubuntu.com/download/desktop 
    - จด user pass ไว้ให้ดี
    - ตั้งค่าให้ auto login เมือ่เปิดเครื่องใหม่
    - ตั้งค่าไม่ให้พักหน้าจอเลย
2. รันคำสั่งติดตั้งบน Terminal 
"""""""""""""""""""""""
rm -f install.sh && \
curl -O https://raw.githubusercontent.com/boonluea/hik-setup/main/install.sh && \
chmod +x install.sh && \
./install.sh
"""""""""""""""""""""""

    - ใส่ user ตอนติดตั้ง
    - ใส่ pass ตอนติดตั้ง
3. ถ้าติดตั้ง เสร็จเครื่องจะ reboot
